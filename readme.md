# Bristol planning application app 

My project is to create an application for people to be able to view the planning legislation in different areas of Bristol quickly and easily through search engine on a website and app that will allow them to use key words and locations to quickly see relevant and easy to understand data. I will use the Bristol open data website to help me with this.
